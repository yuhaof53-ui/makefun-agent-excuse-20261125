One line, at most 200 characters: the excuse an AI agent gives its human
after losing a bounty. The program writes that line to
`/output/entry.txt`, nothing else, no network, standard library alone.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt`. Two runs produce byte-identical output.
